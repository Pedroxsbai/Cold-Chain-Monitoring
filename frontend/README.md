# Frontend — Cold Chain Monitoring

React 19 + Vite + TypeScript, React Router, SWR (cache et actualisation automatique), ApexCharts.

```bash
npm install
npm run dev      # http://localhost:5173, l'API Django (port 8000) est servie via le proxy /api
npm run build    # vérification TypeScript + build de production dans dist/
npm run lint
```

Voir le README à la racine du dépôt pour l'ensemble du projet.
